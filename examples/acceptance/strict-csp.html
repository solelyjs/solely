本页 CSP style-src 'self'，没有 'unsafe-inline'。 主入口自动注入的内联 <style> 会被浏览器拦下，主题变量必须靠手动 <link> 引入。

组件样式观察区

移除 link 后，下面的 input / button / progress 会明显塌陷（颜色、边框、高度丢失）—— 这就是「自动注入被拦、未手动引入」的后果。恢复 link 后应还原。 组件若走 adoptedStyleSheets 则部分结构样式可能仍在，属正常差异。
