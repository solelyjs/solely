#4 ::part() 自定义样式

                

                    ::part(base) 加蓝框；::part(group) 加浅蓝底 + padding: 8px + 虚线 outline，
                    应看到一圈底色包住输入框。注意：group 是无 padding 的纯结构包装层（为 addonBefore / addonAfter 服务），
                    base 自带实色背景与圆角；若只给 group 设背景而不加 padding / border，背景会被 base 盖住，
                    只有四个圆角外露色——这是正常 CSS 层叠，不是组件 bug。
                    布局 / 尺寸 / 定位类整体样式用 ::part(group)；背景 / 边框类样式仍应作用于 ::part(base)。
                

                
            


            
            

                
B · 原生表单关联（#11）

                

                不拦截提交时浏览器会先做约束校验（必填留空应弹原生气泡）。填好后提交，下方显示真实 FormData；
                reset 后看组件值与 change.detail.source === 'reset'。
                声明式 <solely-select-option> 的文本必须写在元素内容里（下拉是 slot 投影、选中态读 childNodes）；
                只写 label 属性会导致下拉空白、选中后显示 value。
                级联禁用说明：fieldset[disabled] 走 formDisabledCallback，
                只记录内部 formDisabled，不会改写作者设置的 el.disabled——所以禁用时
                input.disabled 仍为 false 是设计，要看 aria-disabled="true"、
                shadow 内原生 input 的 tabindex="-1"，以及点击 / Tab 是否被拦截；不清空值、不派发 change。

E · 打包产物（#24，命令行）

npm run build
npm run check:exports          # 期望：140 个导出目标全部存在
npm run check:dist-fresh       # 期望：198 个构建输入指纹一致
npm pack                       # 产出 solely-0.8.0.tgz

mkdir -p /tmp/solely-smoke && cd /tmp/solely-smoke && npm init -y
npm i /path/to/solely/solely-0.8.0.tgz
node --input-type=module -e "import('solely').then(m=>console.log('main', typeof m.BaseElement))"
node --input-type=module -e "import('solely/compiler').then(m=>console.log('compiler', typeof m.buildIR))"
node -e "const s=require('solely'); console.log('cjs', typeof s.BaseElement)"
tar -tf solely-0.8.0.tgz | grep -E "package/dist/(index|plugin|compiler/index|components/theme/variables)"
