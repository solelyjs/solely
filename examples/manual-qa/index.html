Solely 0.8.0 手工验收（本批改动）

覆盖文档页没有的场景：Shadow DOM 焦点、Esc 嵌套、tree disabled 级联、upload 并发、select 异步等。 每节末尾的蓝色框是预期结果；右下角是操作日志。

验收台（浮层/Esc） 组件文档 示例画廊 刷新页面

1. Modal 内输入框：Shadow 焦点与 Tab

打开后点进输入框，连续按 Tab；焦点应向后移动，不应被拉回第一个控件。

预期：日志显示焦点依次经过 input → 下一个按钮；modal 关闭后焦点回到触发按钮。

2. Modal 内 Tooltip：Esc 级联

打开 modal → 点击内容里的按钮弹出 tooltip → 按 Esc。

预期：tooltip 先关闭，modal 同时关闭；日志出现 tooltip false 与 modal closed，且 tooltip 不阻断 Esc。

3. Tree：disabled 级联与显式 key

树可勾选；父节点下有一个 enabled、一个 disabled 子节点。

预期：勾选父节点后 keys 只有 p、p-1；显式写入 p-2 后保留该 key，父节点呈半选。

4. Upload：并发队列补位

max-concurrency=1，选择 2 个文件后删除正在上传的第一个。

预期：日志先出现 customRequest #1 开始；删除后出现 #1 abort 与 #2 开始，队列不卡死。

5. Select：异步 options / 缺 label / 静默写值

挂载后再异步赋值 options，第二个选项故意不带 label。

预期：异步设置后选项出现（也可用“打开下拉”直接验证）；在输入框按 b 首字母搜索不报错； el.value 不产生 change，setValue 产生一次 CustomEvent（detail.source=api）； “打开并按 ↑”应高亮最后一项；“下拉打开时按 Tab”应收起下拉。

6. Table：数组 dataSource

整体替换数组生效；原地 push 不会自动重渲染。

预期：整体替换后行数立即变化；getDataSource() 的 push 自动 +1； 调用方原始数组 push 后行数不变，调用 refresh() 后 +1。

7. Pagination：setCurrent 夹取与事件

预期：999 夹到 10、0 夹到 1，各派发一次 change（detail 含 current/pageSize）。

8. Tabs：setItems 回退

预期：切换后 activeKey 回退到 c，内容区不空白。

9. Coordinate Input：秒输入框同步

预期：setValue / clear 后，秒输入框与十进制值一致，没有旧值残留。

10. Divider：纯图标插槽

图标通过 sprite 属性从 public/icons/bootstrap-icons.svg 加载； 不提供图标源时组件按约定只渲染空白占位。

预期：蓝色星形图标显示在分割线中间；不应被判定为“无内容”而丢弃。

11. Steps：动态修改子步骤属性

预期：标题立即更新，第二步进入禁用态，无需重新挂载。

12. Card / Empty：坏图回退与重渲染

预期：图片回退到内置占位图；触发一次重渲染后仍是占位图，不重新破图。
