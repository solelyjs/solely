Select 选择器

下拉选择器组件，用于从多个选项中选择一项。支持自动调整下拉框位置、图标选项等功能。

基础用法

最简单的用法，通过 options 属性传入选项列表（JSON 字符串格式）。

<solely-select options='[{"label":"选项1","value":"1"},{"label":"选项2","value":"2"}]'></solely-select>

不同尺寸

通过 size 属性设置选择器尺寸，可选 small、medium（默认）、large。

<solely-select size="small" options='[...]'></solely-select>
<solely-select size="medium" options='[...]'></solely-select>
<solely-select size="large" options='[...]'></solely-select>

可清除

通过 clearable 属性设置是否显示清除按钮。

<solely-select clearable options='[...]'></solely-select>

禁用状态

通过 disabled 属性禁用选择器。

<solely-select disabled options='[...]'></solely-select>

禁用选项

可以在选项中设置 disabled 属性来禁用单个选项。

<solely-select options='[{
  "label": "可用选项",
  "value": "1"
}, {
  "label": "禁用选项",
  "value": "2",
  "disabled": true
}, ...]'>
</solely-select>

事件处理

监听 change 事件获取选中的值，监听 clear 事件处理清除操作。通过 event.target.value 获取当前选中的值。

事件语义：只有值真正发生变化时才派发 change；初始化、属性同步（如设置 value 属性）不派发。 用户交互与显式 setValue() / .value= 会派发；写入相同值（含点击已选中项）不会重复派发。 多选时任何路径的 event.target.value 都是数组，重复值会自动去重。

选中: {{$data.selectedLabel || '无'}} 
<!-- HTML -->
<solely-select 
  options='[...]' 
  @change="handleChange(event)"
  @clear="handleClear()">
</solely-select>

<!-- JavaScript -->
const select = document.querySelector('solely-select');

select.addEventListener('change', (e) => {
  // 通过 event.target.value 获取选中的值
  const value = e.target.value;
  console.log(`选中值: ${value}`);
});

select.addEventListener('clear', (e) => {
  console.log('已清除');
});

  // 多选时这里是数组，例如 ["vue","react"]
  console.log(event.target.value);
});

表单关联

设置 name 后，solely-select 作为表单关联自定义元素参与提交： 单选提交一个条目，多选以同一字段名提交多个条目；未选择时不产生任何条目。 required 为空时会阻断提交，formResetCallback 回到 default-value（未设置则回到初始 value）， 所属 fieldset 禁用时会清空提交值、按有效禁用态设置 aria-disabled 并把组合框触发器移出 Tab 序列；不会改写作者设置的 disabled，fieldset 恢复后自动还原。

    <solely-select-option value="beijing">北京</solely-select-option>
    <solely-select-option value="shanghai">上海</solely-select-option>
  </solely-select>

  <solely-select name="tags" multiple>
    <solely-select-option value="a">A</solely-select-option>
    <solely-select-option value="b">B</solely-select-option>
  </solely-select>

  <button type="submit">提交</button>

数据源与优先级

组件支持 options 属性、setOptions() 方法与插槽三种数据源，优先级从高到低为： options 属性（显式变更） > setOptions() > 插槽。

  • 默认：存在 <solely-select-option> 或带 data-value 的子元素时使用插槽；否则使用 options 属性。
  • 调用 setOptions() 后立即使用传入的列表，并锁定为 options 数据源：插槽增删不会抢占，重新挂载后仍然保留。
  • 之后若设置或修改 options 属性：以属性为准，并解除 setOptions() 的锁定。
  • 若移除 options 属性：恢复最近一次 setOptions() 的结果；没有则回到插槽 / 空列表。
  • 分组标题（options 中的 isGroup: true 或插槽中的 data-group）是结构性节点： 不可点击、不可键盘高亮/选中，也不会出现在 getOptions() 的返回值中。
  • 多选值在写入时会自动去重（保持首次出现顺序），因此点击一次即可完全取消重复值。

类型定义

// 选择器尺寸类型
type SelectSize = 'small' | 'medium' | 'large';

// 图标类型 - 安全的使用方式
type SelectIcon = 
  | string                                          // CSS 类名（同时暴露为 part，如 'icon-user' → ::part(icon-user)）
  | HTMLElement                                     // DOM 元素（推荐用于 SVG、图片等）
  | (option: SelectOption) => string | HTMLElement;  // 函数返回图标

// 选项数据
interface SelectOption {
  label: string;                    // 选项标签
  value: string;                    // 选项值
  disabled?: boolean;               // 是否禁用
  isGroup?: boolean;                // 分组标题（不可选中）
  icon?: SelectIcon;               // 选项图标（string 仅作为 CSS 类名）
  render?: (option: SelectOption) => string | HTMLElement;  // 完全自定义渲染
}

// 选择器属性接口
interface SelectProps {
  value?: string | string[]; // 选中的值（多选为数组）
  placeholder?: string;  // 占位符
  disabled?: boolean;   // 是否禁用
  size?: SelectSize;   // 尺寸
  clearable?: boolean;  // 是否可清除
  options?: SelectOption[]; // 选项列表
  multiple?: boolean;  // 是否多选，开启后 value 为数组
  block?: boolean;    // 是否块级显示
  name?: string;     // 表单字段名
  required?: boolean;  // 是否必选
  defaultValue?: string; // 重置默认值
  invalidMessage?: string; // 自定义校验提示
}

icon / render 会同时用于下拉选项、单选触发区和多选标签，保证选中前后展示一致。 由于 HTMLElement 与函数无法通过 JSON 序列化，这两项只能通过 setOptions() 或 .options 以程序化方式传入；options 属性中 icon 仅支持 CSS 类名字符串。 render() 返回字符串时按纯文本渲染，不会解析 HTML；未提供图标或自定义渲染时自动回退为纯文本。
字符串类名图标：类名会同时作为 part 暴露，例如 icon="icon-gear" 可用 solely-select::part(icon-gear) 定位；但组件使用 Shadow DOM，document 中的全局 .icon-gear 规则不会自动跨树生效——需要把该类样式注入组件 shadow（例如项目若用 adoptedStyleSheets 管理样式，可把同一张 CSSStyleSheet 追加到 select.shadowRoot.adoptedStyleSheets，此时类名模式成立）。若不想处理样式注入， 请使用 HTMLElement（图片 / SVG）或 render() 传入图标节点。

插槽使用说明

当需要在选项中使用复杂的 HTML 结构（如图标、图片、多行文本等）时，可以使用插槽方式：

<!-- 推荐：声明式选项，label 缺省取文本内容 -->
<solely-select>
  <solely-select-option value="value1" label="显示文本">
    <!-- 任意自定义内容 -->
    <img src="icon.png">
    <span>选项文本</span>
  </solely-select-option>

  <!-- 兼容写法：div + data-value/data-label 仍然可用 -->
  <div data-value="value2" data-label="选项 2" disabled>...</div>
</solely-select>

插槽选项属性：

  • <solely-select-option>：声明式选项；value 为值，label 为选中后展示文本（缺省取元素文本内容）
  • data-value（兼容写法必需）：选项的值
  • data-label（兼容写法可选）：选中后显示的标签，默认使用元素文本内容
  • disabled（可选）：禁用该选项
  • data-group（可选）：标记为分组标题，不可点击/键盘选中，也不会出现在 getOptions() 中
  • 选项的 flex 布局、内边距、hover/选中/禁用样式由组件统一提供； 只需自定义业务内容样式（如头像尺寸、徽章颜色），无需重复写 display:flex / align-items / padding / cursor。
