Pagination 分页

用于数据分页展示，支持页码切换、快速跳转、每页条数设置等功能。

基础用法

最简单的用法，通过 current 设置当前页，total 设置数据总数。

<solely-pagination
  current="1"
  total="50">
</solely-pagination>

显示总数

设置 show-total 属性显示数据总数。

<solely-pagination
  current="1"
  total="100"
  show-total>
</solely-pagination>

快速跳转

设置 show-quick-jumper 属性显示快速跳转输入框。

<solely-pagination
  current="1"
  total="100"
  show-quick-jumper>
</solely-pagination>

每页条数选择

设置 show-size-changer 属性显示每页条数选择器。

<solely-pagination
  current="1"
  total="100"
  show-size-changer>
</solely-pagination>

不同尺寸

支持 small、medium（默认）、large 三种真实档位，按钮高度与字号逐档增大。

<solely-pagination current="1" total="50" size="small"></solely-pagination>
<solely-pagination current="1" total="50" size="medium"></solely-pagination>
<solely-pagination current="1" total="50" size="large"></solely-pagination>

禁用状态

设置 disabled 属性禁用分页组件。

<solely-pagination
  current="1"
  total="50"
  disabled>
</solely-pagination>

大量数据

当数据量较大时，会自动折叠页码显示。

<solely-pagination
  current="5"
  total="1000"
  show-total
  show-quick-jumper>
</solely-pagination>

简单模式

设置 simple 属性后只保留首页、当前页和末页，中间页码用省略号压缩，并移除页码边框。

<solely-pagination
  current="5"
  total="1000"
  simple>
</solely-pagination>

完整功能

展示分页组件的完整功能组合。

<solely-pagination
  current="1"
  total="100"
  show-total
  show-size-changer
  show-quick-jumper>
</solely-pagination>

CSS Part 自定义样式

通过 ::part() 伪元素可在 Shadow DOM 外部分页组件内部样式，无需修改组件源码。

<!-- HTML -->
<solely-pagination current="3" total="100" show-total></solely-pagination>

<!-- CSS：通过 ::part() 自定义样式 -->
<style>
  solely-pagination::part(item) {
    border-radius: 8px;
    border: 1px solid #d9d9d9;
    transition: all 0.2s;
  }
  solely-pagination::part(item):hover {
    border-color: #1890ff;
    color: #1890ff;
  }
  solely-pagination::part(item-active) {
    background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    color: #fff;
    box-shadow: 0 4px 12px rgba(102, 126, 234, 0.4);
  }
  solely-pagination::part(total) {
    color: #666;
    font-weight: 500;
  }
</style>

事件演示

切换页码或每页条数查看事件触发情况。

事件日志（最近5条）：

<!-- HTML -->
<solely-pagination
  current="1"
  total="100"
  @change="handleChange(event)"
  @size-change="handleSizeChange(event)">
</solely-pagination>

<!-- JavaScript -->
const pagination = document.querySelector('solely-pagination');

// 页码改变事件
pagination.addEventListener('change', (e) => {
  console.log('当前页:', e.detail.current);
  console.log('每页条数:', e.detail.pageSize);
});

// 每页条数改变事件（兼容旧名称 show-size-change）
pagination.addEventListener('size-change', (e) => {
  console.log('当前页:', e.detail.current);
  console.log('每页条数:', e.detail.pageSize);
});

API

属性

HTML 属性写法 JS 属性写法 说明 类型 默认值
current current 当前页码 number 1
total total 数据总数 number 0
page-size pageSize 每页条数 number 10
size size 组件尺寸，可选值为 small、medium、large 'small' | 'medium' | 'large' 'medium'
size 兼容别名 size 兼容别名：middle / default → medium，解析时归一，不作为独立档位 'middle' | 'default' —
simple simple 是否使用简单模式（只显示首页、当前页、末页，中间用省略号压缩） boolean false
show-total showTotal 是否显示总数据数 boolean false
show-quick-jumper showQuickJumper 是否显示快速跳转 boolean false
show-size-changer showSizeChanger 是否显示每页条数选择器 boolean false
page-size-options pageSizeOptions 每页条数选项（JSON字符串）。当前 page-size 不在选项中时会自动并入并升序排列，保证下拉显示值始终与实际每页条数一致 string [10, 20, 50, 100]
disabled disabled 是否禁用 boolean false

事件

事件名 说明 回调参数
change 页码或每页条数改变时触发；挂载初始化与 attribute 同步不派发 CustomEvent<{ current: number; pageSize: number }>
size-change 通过每页条数选择器改变时触发（与 change 同时派发） CustomEvent<{ current: number; pageSize: number }>
show-size-change 已废弃：size-change 的旧别名，内容完全相同，后续大版本移除 CustomEvent<{ current: number; pageSize: number }>

类型定义

// 分页尺寸
type PaginationSize = 'small' | 'medium' | 'large'; // middle / default 为兼容别名 → medium

// 分页属性接口
interface PaginationProps {
  current?: number;           // 当前页码
  total?: number;             // 数据总数
  pageSize?: number;          // 每页条数
  size?: PaginationSize;    // 组件尺寸
  simple?: boolean;          // 是否使用简单模式
  showTotal?: boolean;       // 是否显示总数
  showQuickJumper?: boolean; // 是否显示快速跳转
  showSizeChanger?: boolean; // 是否显示条数选择
  disabled?: boolean;        // 是否禁用
}
