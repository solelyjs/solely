Table 表格

表格组件，用于展示结构化数据。

基础用法

通过 columns 和 data-source 属性传入表格配置和数据（JSON 字符串格式）。

<!-- HTML 中通过 JSON 字符串传递 -->
<solely-table 
  columns='[{"title":"姓名","dataIndex":"name"},...]' 
  data-source='[{"name":"张三","age":28},...]'
></solely-table>

通过属性绑定设置数据

在 Solely 模板中使用 :columns 和 :dataSource 绑定组件数据，无需手写 JSON 字符串。

加载数据 清空数据 
<!-- 使用 :prop 绑定组件数据 -->
<solely-table 
  :columns="this.columns" 
  :dataSource="this.dataSource"
></solely-table>

<!-- JavaScript -->
const columns = [
  { title: '姓名', dataIndex: 'name', key: 'name' },
  { title: '年龄', dataIndex: 'age', key: 'age' },
  { title: '地址', dataIndex: 'address', key: 'address' }
];

const dataSource = [
  { name: '张三', age: 28, address: '北京市' },
  { name: '李四', age: 32, address: '上海市' },
  { name: '王五', age: 24, address: '广州市' }
];

通过 JS API 设置数据

在 JavaScript 中使用 setColumns 和 setDataSource 方法动态设置数据。

加载数据 清空数据 
<!-- HTML -->
<solely-table ref="myTable"></solely-table>

<!-- JavaScript -->
const table = document.querySelector('solely-table');

// 使用 setColumns 设置列配置
table.setColumns([
  { title: '姓名', dataIndex: 'name', key: 'name' },
  { title: '年龄', dataIndex: 'age', key: 'age' },
  { title: '地址', dataIndex: 'address', key: 'address' }
]);

// 使用 setDataSource 设置数据
table.setDataSource([
  { name: '张三', age: 28, address: '北京市' },
  { name: '李四', age: 32, address: '上海市' },
  { name: '王五', age: 24, address: '广州市' }
]);

可点击行

设置 row-clickable 属性使表格行可点击，点击时触发 row-click 事件；行同时可聚焦，键盘 Enter/Space 与点击等价，触发 row-click。开启 selectable 且未开启 row-clickable 时，行聚焦后 Enter/Space 切换该行选中状态。开启 selectable 时复选框仍是唯一的 Tab 停点，行聚焦使用 tabindex="-1"，不会与复选框重复。

事件日志（最近5条）：
点击表格行查看事件...
<!-- HTML -->
<solely-table 
  row-clickable 
  @row-click="handleRowClick(event)"
  columns="..." 
  data-source="..."
></solely-table>

<!-- JavaScript -->
const tableEl = document.querySelector('solely-table');

tableEl.addEventListener('row-click', (e) => {
  const { row, index } = e.detail;
  console.log('点击了第', index + 1, '行:', row);
});

排序（本地）

列设置 sortable 后可点击表头排序，顺序为 升序 → 降序 → 取消。 表头支持 Enter / Space 键操作，并输出 aria-sort。 默认在组件内本地排序并派发 sort-change；远端排序请设置 remote，组件只管理状态并派发事件。 

<!-- 列级 sortable，默认本地排序 -->
<solely-table
  row-key="id"
  columns='[{"title":"年龄","dataIndex":"age","key":"age","sortable":true}]'
  data-source="..."
></solely-table>

// 监听排序变化
table.addEventListener('sort-change', (e) => {
  // e.detail: { column, order, sort }
  // order: 'asc' | 'desc' | ''
});

筛选（内置筛选行 + API）

列级 filters 声明可选值后，表头下方会渲染内置筛选行（复选框 + 清除），默认在组件内本地过滤； 也可以继续用 API 设置/清除筛选。远端筛选请设置 remote，组件只派发 filter-change。 筛选与排序可以同时生效。

仅看活跃 年龄升序 清除筛选 
// 设置单列筛选（传空值等于清除该列）
table.setFilter('status', 'active');
table.setFilter('status', ['active', 'inactive']);

// 批量设置 / 清除
table.setFilterValues({ status: ['active'] });
table.clearFilters();
table.clearFilters('status');

// 与排序同时生效
table.setSort('age', 'asc');
table.clearSort();

受控排序与筛选

传入 sort / filter-values 即进入受控模式：组件只派发事件、不修改内部状态， 需要把事件 detail 回写到属性上。属性存在即受控；切换回非受控请通过 property 赋值为 undefined。

筛选活跃 筛选禁用 清除筛选
当前受控状态：sort = {{$data.controlledSort ? $data.controlledSort.column + ' / ' + $data.controlledSort.order : '无'}}， filters = {{$data.controlledFilterText}} 
<solely-table
  :sort="$data.controlledSort"
  :filterValues="$data.controlledFilters"
  @sort-change="this.handleControlledSort(event)"
  @filter-change="this.handleControlledFilter(event)"
></solely-table>

// 事件 detail 即「期望的下一个状态」，回写后生效；与左侧实际 demo 的方法名一致
handleControlledSort(e) { this.$data.controlledSort = e.detail.sort ?? { column: '', order: '' }; }
handleControlledFilter(e) { this.$data.controlledFilters = e.detail.filters ?? {}; }

行选择

设置 selectable 显示选择列，row-key 用于跨数据刷新保留选择； 多选模式支持表头全选与半选（indeterminate），selection-mode="single" 为单选。

清空选择 {{$data.selectionSummary}} 
<solely-table
  selectable
  row-key="id"
  selection-mode="multiple"
  @selection-change="this.handleSelectionChange(event)"
></solely-table>

// e.detail: { selectedKeys, selectedRows, row?, selected? }
// 受控：设置 selected-keys 后只派发事件，不修改内部状态

展开行

设置 expandable 后每行出现展开按钮；展开内容优先使用 expand-{key} 插槽 （未配置 rowKey 时为 expand-{rowIndex}），也可以通过 expandRender 渲染函数提供。

工号：A001 · 部门：研发部
工号：A002 · 部门：市场部
工号：A003 · 部门：设计部
 {{$data.expandSummary}} 
<solely-table expandable row-key="id">
  <div slot="expand-1">第一行的展开内容</div>
</solely-table>

// 或使用渲染函数（property 赋值）
table.expandRender = (row, index) => {
  const el = document.createElement('div');
  el.textContent = `${row.name} 的详情`;
  return el; // 返回 Node；返回字符串按纯文本插入
};

自定义空态

无数据时复用 solely-empty，可通过 slot="empty" 完全自定义； 默认本地筛选下，筛选结果为空也会展示空态；remote 模式由使用方决定传入的数据。

暂无员工数据，请先添加 
<solely-table data-source="[]">
  <div slot="empty">暂无员工数据，请先添加</div>
</solely-table>

与分页联动

table 不执行分页逻辑。监听 pagination 的 change，自行加载/切片数据并调用 table.handlePaginationChange(event.detail)，table 会把分页事件转出为 page-change； 数据源替换时还会派发 data-change（包含 total）供外部同步分页总数。 这里把每页条数选项设为 [2, 4, 6]，下拉显示值始终与 page-size 一致。

{{$data.pageSummary}} 
// pagination 的 change 事件 detail: { current, pageSize }
handlePageChange(event) {
  const { current, pageSize } = event.detail;
  const start = (current - 1) * pageSize;
  const rows = allRows.slice(start, start + pageSize);

  table.setDataSource(rows);              // 触发 data-change
  table.handlePaginationChange(event.detail); // 转出 page-change
}

// 远端分页时同理：拿到页码后请求接口，再 setDataSource

自定义单元格内容

推荐在列定义中声明 render(row, index)：返回 Node 直接挂载，返回字符串按纯文本插入（防 XSS）， 可按行拿到数据；也可使用插槽：列级 slot（所有行共用同一内容）或行级稳定插槽 col-{key}-{rowKey}（需配置 row-key，排序/筛选/分页后仍跟随原数据行）。 旧的 col-{key}-{rowIndex} 按展示索引定位，仅作兼容回退。 优先级为 render > slot > 稳定插槽 > 旧版插槽 > 字段值；稳定与旧版同时存在时稳定插槽优先。

● 活跃 ● 禁用 编辑 查看 
// 推荐：列级 render（可通过 property / setColumns 传入函数）
table.setColumns([
  { title: '状态', dataIndex: 'status', key: 'status',
    render: (row) => row.status === 'active' ? '● 活跃' : '● 禁用' },
  { title: '操作', dataIndex: 'action', key: 'action',
    render: (row, index) => {
      const button = document.createElement('solely-button');
      button.textContent = '编辑';
      return button;
    } },
]);

<!-- 或者使用插槽 -->
<solely-table row-key="id" columns="..." data-source="...">
  <!-- col-status-1: 稳定定位到 id=1 的行的 status 列 -->
  <span slot="col-status-1" style="color: #52c41a;">● 活跃</span>
  <span slot="col-status-2" style="color: #ff4d4f;">● 禁用</span>
  
  <!-- col-action-1: 稳定定位到 id=1 的行的 action 列 -->
  <solely-button slot="col-action-1" type="primary" size="small">编辑</solely-button>
  <solely-button slot="col-action-2" size="small">查看</solely-button>
</solely-table>

插槽

插槽名 说明
col-{key}-{rowKey} 按行自定义单元格内容（推荐）：key 为列的 key，rowKey 为稳定的行标识。例如配置 row-key="id" 后，col-name-1 始终指向 id=1 的行，排序/筛选/分页后不会漂移
col-{key}-{rowIndex} 旧版按展示索引定位的单元格插槽（兼容保留）；索引会随排序/筛选/分页变化，推荐改用上面的稳定写法。稳定插槽与它同时存在时稳定插槽优先
{col.slot} 列级具名插槽：在列定义声明 slot 后，所有行共用同一插槽内容（模板引擎无作用域插槽，拿不到行数据）；按行动态渲染请用 render
expand-{key} / expand-{rowIndex} 展开行内容。配置了 rowKey 时插槽名为 expand-4（4 为行 key），否则为 expand-0（0 为行索引）；与 expandRender 同时存在时 slot 优先。
限制：展开插槽名按 row[key] 直接取字段，rowKey 为嵌套路径（如 user.id）时取不到值会回退为行索引； 嵌套 rowKey 场景请改用 expandRender，或把 rowKey 改为扁平字段（单元格插槽 col-{key}-{rowKey} 支持嵌套路径）。
empty 自定义空态内容；未提供时复用 solely-empty 显示「暂无数据」

受控语义与已知限制

  • 受控判定：sort / filterValues / selectedKeys / expandedKeys 一旦有值即进入受控模式；组件只派发事件，不修改内部状态，需要把事件 detail 回写。清除受控请通过 property 赋值为 undefined（移除 attribute 会被框架回落为旧值）。
  • 排序 / 筛选默认本地生效：传了 sortable 点击表头即本地排序；传了 filters 会渲染内置筛选行并本地过滤。远端排序/筛选请设置 remote，组件只管理状态并派发事件。
  • 本地比较规则：优先使用列级 sorter；否则数字按数值、Date 按时间、其余按字符串 localeCompare。本地筛选按 String(cell) === String(value) 匹配，多值之间为「或」关系；dataIndex 支持 user.name、items[0].name、items.0.name。
  • 行标识：选择/展开以及行级单元格插槽定位（col-{key}-{rowKey}）都按 rowKey 保留；未配置 rowKey 时按行对象引用生成稳定 id，排序/筛选后身份不变，但整体替换数据源（新对象）后仍会变化，建议开启这些能力时始终配置 rowKey。开发环境会提示一次。
  • 固定列：多个左/右固定列会按列宽累加偏移；选择列随左固定列贴左、展开列随右固定列贴右。建议为固定列显式设置 width，无法解析的宽度会在运行时按实测宽度补足。
  • 性能（已知限制）：表格仍是整表重渲染，每次刷新都会重建所有行的 DOM。大数据量（例如几千行）建议配合分页/虚拟滚动使用；未引入增量更新，以避免破坏现有渲染与测试契约。
  • 展开内容：expandRender 返回字符串按纯文本插入（防 XSS），需要富文本/组件请使用 slot；渲染函数会在每次刷新后重新执行，返回新 Node 时旧节点会被替换。
  • 分页：table 不做分页计算，仅通过 handlePaginationChange 转出 page-change；数据源替换时派发 data-change，其 total 为当前数据源条数。

类型定义

// 表格列配置
interface TableColumn {
  title: string;           // 列标题
  dataIndex: string;       // 列数据字段，支持 user.name / items[0].name
  key: string;           // 列标识
  width?: number | string; // 列宽度
  fixed?: 'left' | 'right'; // 是否固定列
  align?: 'left' | 'center' | 'right'; // 对齐方式
  render?: (row, index) => string | Node | null; // 列级渲染，字符串按纯文本插入
  slot?: string;         // 列级具名插槽（所有行共用）
  sortable?: boolean;     // 是否可点击表头排序
  sorter?: (a, b) => number; // 自定义比较（本地排序时生效，需 property 传入）
  filters?: TableFilterOption[]; // 可选筛选值，声明后渲染内置筛选行
}

// 排序 / 筛选状态
interface TableSortState {
  column: string;         // 列 key
  order: 'asc' | 'desc';   // 方向
}
interface TableFilterOption {
  label: string;
  value: string | number | boolean;
}

// 组件属性接口
interface TableProps {
  columns?: string;      // 表格列配置（JSON字符串）
  dataSource?: string;   // 表格数据（JSON字符串）
  size?: 'small' | 'medium' | 'large'; // 表格尺寸（middle / default 为兼容别名 → medium）
  bordered?: boolean;    // 是否显示边框
  loading?: boolean;     // 是否加载中
  striped?: boolean;     // 是否显示斑马纹
  rowClickable?: boolean; // 是否可点击行
  rowKey?: string;       // 行标识：选择/展开/单元格插槽 col-{key}-{rowKey} 定位
  selectable?: boolean;    // 是否显示选择列
  selectionMode?: 'multiple' | 'single';
  selectedKeys?: string[]; // 受控选择
  expandable?: boolean;    // 是否显示展开列
  expandedKeys?: string[]; // 受控展开
  expandRender?: (row, index) => Node | string;
  sort?: TableSortState | string; // 受控排序
  filterValues?: Record<string, string[]> | string; // 受控筛选
  localSort?: boolean;    // 组件内排序，默认 true
  localFilter?: boolean;  // 组件内过滤，默认 true
  remote?: boolean;       // 远端模式，关闭本地排序/筛选
}
