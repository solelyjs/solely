Upload 上传

文件上传组件，支持点击上传和拖拽上传。

基础用法

最简单的用法，点击上传文件。文档站没有后端，已统一注入 mock 上传（进度 → 成功）；组件在未配置 action 或 customRequest 时会把文件标记为失败，见「无上传目标与自定义请求」样例。

<solely-upload></solely-upload>

自定义按钮文字

通过 button-text 属性自定义上传按钮文字。

<solely-upload button-text="上传图片"></solely-upload>
<solely-upload button-text="选择文件"></solely-upload>

多文件上传

设置 multiple 属性支持多文件上传。

<solely-upload multiple button-text="上传多个文件"></solely-upload>

限制文件类型

通过 accept 属性限制可上传的文件类型。

<solely-upload accept="image/*" button-text="只能上传图片"></solely-upload>
<solely-upload accept=".pdf,.doc,.docx" button-text="只能上传文档"></solely-upload>

拖拽上传

设置 drag 属性开启拖拽上传模式。

<solely-upload drag></solely-upload>

禁用状态

通过 disabled 属性禁用上传功能。

<solely-upload disabled></solely-upload>

限制数量

通过 max-count 属性限制最多上传文件数量。

<solely-upload multiple max-count="3" button-text="最多上传3个文件"></solely-upload>

限制大小

通过 max-size 属性限制单个文件大小（字节）。max-size=0（或负数、未设置）表示不限制大小，保留旧版语义。

<!-- 1MB = 1024 * 1024 = 1048576 字节 -->
<solely-upload max-size="1048576" button-text="单个文件不超过1MB"></solely-upload>

请求配置

通过 action、method、headers、name、data、with-credentials、timeout 对接真实后端。默认方法为 POST，默认字段名为 file。文档站没有 /api/upload 后端，已注入 mock 上传让示例可成功演示；真实项目移除 mock 后由 action 发起请求。未配置 action 或 custom-request 时按失败处理（error 事件 + 列表错误信息），见 0.8.0 样例。

<solely-upload
  action="/api/upload"
  method="PUT"
  name="avatar"
  headers='{"Authorization":"Bearer demo-token"}'
  data='{"biz":"demo"}'
  with-credentials
  timeout="10000"
></solely-upload>

<!-- 额外表单字段会与文件一起以 multipart/form-data 提交 -->

before-upload / custom-request

两个钩子只能通过 JS 属性赋值（不支持 HTML attribute）。before-upload 可返回 false 拒绝、返回 Promise 等待、或返回一个新的 File 替换待上传文件； custom-request 可完全接管上传过程，由实现主动调用 onProgress / onSuccess / onError，并可返回 { abort } 供组件取消。

两个钩子只能通过 JS 属性赋值（不支持 HTML attribute）。文档站已给这个实例注入 beforeUpload（拒绝 .exe）与 customRequest（模拟进度 / 成功），选文件即可看到完整流程；代码见右侧。 
const upload = document.querySelector('solely-upload');

// 1. before-upload：校验 / 等待 / 替换文件
upload.beforeUpload = async (file) => {
  if (file.name.endsWith('.exe')) return false;           // 拒绝，组件派发 error
  await checkPermission(file);                                    // 返回 Promise 时等待
  return file;                                                     // 也可 return new File(...) 替换
};

// 2. custom-request：完全接管上传
upload.customRequest = ({ file, uploadFile, action, method, headers, name, data, withCredentials, onProgress, onSuccess, onError }) => {
  const controller = new AbortController();
  fetch(action, {
    method,
    headers,
    body: buildFormData({ file, name, data }),
    credentials: withCredentials ? 'include' : 'same-origin',
    signal: controller.signal,
  })
    .then(response => {
      if (!response.ok) throw new Error(`HTTP ${response.status}`);
      return response.json();
    })
    .then(data => onSuccess(data))
    .catch(error => onError(error));

  return { abort: () => controller.abort() };
};

事件处理

监听 change、progress、success、error、cancel、remove 事件处理上传逻辑。progress 事件同时携带单文件 percent 与 overallPercent（整体进度）。

事件日志（最近5条）：
等待交互...
<!-- HTML -->
<solely-upload 
  @change="handleChange(event)"
  @progress="handleProgress(event)"
  @success="handleSuccess(event)"
  @error="handleError(event)"
  @cancel="handleCancel(event)"
  @remove="handleRemove(event)"
></solely-upload>

<!-- JavaScript -->
const uploadEl = document.querySelector('solely-upload');

// change 事件 - 文件列表变化时触发
uploadEl.addEventListener('change', (e) => {
  const fileList = e.target.fileList;
  console.log('文件列表:', fileList);
});

// progress 事件 - 单个文件进度（0-100，单调不减）
uploadEl.addEventListener('progress', (e) => {
  console.log('进度:', e.detail.file.name, `${e.detail.percent}%`, `整体 ${e.detail.overallPercent}%`);
});

// success 事件 - 上传成功时触发
uploadEl.addEventListener('success', (e) => {
  console.log('上传成功:', e.detail.file, e.detail.response);
});

// error 事件 - 上传失败 / 校验拒绝时触发，reason 说明来源
uploadEl.addEventListener('error', (e) => {
  console.log('上传失败:', e.detail.message, e.detail.reason);
});

// cancel 事件 - abort / abortAll 取消上传时触发
uploadEl.addEventListener('cancel', (e) => {
  console.log('已取消:', e.detail.file);
});

// remove 事件 - 移除文件时触发
uploadEl.addEventListener('remove', (e) => {
  console.log('移除文件:', e.detail.file);
});

无上传目标与自定义请求（0.8.0）

左侧不配 action / customRequest，选文件后应显示 error；右侧用 customRequest 模拟进度、完成与取消。

未配置上传目标（应 error）
customRequest 模拟上传（进度 / 完成 / 取消）
upload.customRequest = ({ file, onProgress, onSuccess, onError, signal }) => {
  let p = 0;
  const timer = setInterval(() => { p += 25; onProgress(p);
    if (p >= 100) { clearInterval(timer); onSuccess({ url: 'mock://done' }); } }, 300);
  signal.addEventListener('abort', () => clearInterval(timer));
  return { abort: () => { clearInterval(timer); onError('已取消'); } };
};

事件

事件名 说明 回调参数
change 一次文件选择只派发一次汇总 change；clear()/移除文件时各派发一次 Event
success 上传成功时触发，不派发 change CustomEvent<{ file: UploadFile; fileList: UploadFile[]; response?: unknown }>
error 上传失败 / 校验拒绝 / before-upload 拒绝 / 未配置上传目标（reason=missing-action）时触发，reason 说明来源 CustomEvent<{ file: UploadFile; message: string; reason: string }>
progress 单个文件进度变化时触发，percent 与 overallPercent 均为 0-100 且单调不减 CustomEvent<{ file: UploadFile; percent: number; overallPercent: number }>
cancel abort(uid) / abortAll() 取消上传时触发；移除文件或 clear() 时为静默取消 CustomEvent<{ file: UploadFile; fileList: UploadFile[] }>
remove 移除文件时触发 CustomEvent<{ file: UploadFile; fileList: UploadFile[] }>

类型定义

// 上传文件类型（fileList 中不要求是 File 实例，可只提供 name/url/status）
interface UploadFile {
  uid: string;           // 文件唯一标识（外部数据缺失时自动补齐）
  name: string;          // 文件名
  size?: number;         // 文件大小
  type?: string;         // 文件类型
  status?: 'waiting' | 'uploading' | 'done' | 'error' | 'removed' | 'cancelled';
  percent?: number;      // 上传进度（0-100）
  url?: string;         // 文件URL
  error?: string;       // 错误信息
  response?: unknown;    // 服务端响应
}

// 组件属性接口（beforeUpload / customRequest 仅支持 JS 属性赋值）
interface UploadProps {
  action?: string;       // 上传地址
  method?: string;       // 请求方法，默认 POST
  headers?: Record<string, string>;
  name?: string;         // 文件字段名，默认 file
  withCredentials?: boolean;
  data?: Record<string, unknown>;
  timeout?: number;      // 毫秒，0 表示不限制
  maxConcurrency?: number; // 0 表示不限制
  beforeUpload?: UploadBeforeUpload;
  customRequest?: UploadCustomRequest;
  accept?: string;       // 接受上传的文件类型
  multiple?: boolean;   // 是否支持多选
  fileList?: string | UploadFile[]; // JSON字符串或 JS 数组
  listType?: 'text' | 'picture' | 'picture-card';
  disabled?: boolean;   // 是否禁用
  showUploadList?: boolean; // 是否显示上传列表
  buttonText?: string;  // 上传按钮文字
  drag?: boolean;       // 是否支持拖拽上传
  maxCount?: number;   // 最大文件数量
  maxSize?: number;    // 字节；0 表示不限制
  block?: boolean;      // 是否撑满父容器宽度
}
