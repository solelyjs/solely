Breadcrumb 面包屑

显示当前页面在系统层级结构中的位置，并能向上返回。

基础用法

最简单的面包屑，使用 items 属性设置路由栈。

// HTML
<solely-breadcrumb id="breadcrumb"></solely-breadcrumb>

// JavaScript
const breadcrumb = document.getElementById('breadcrumb');
const items = [
    { title: '首页', href: '/' },
    { title: '组件', href: '/components' },
    { title: '面包屑' }
];
breadcrumb.setAttribute('items', JSON.stringify(items));

自定义分隔符

使用 separator 属性自定义分隔符。

// 使用箭头分隔符
breadcrumb.setAttribute('separator', '>');

// 使用竖线分隔符
breadcrumb.setAttribute('separator', '|');

// 使用箭头符号
breadcrumb.setAttribute('separator', '→');

点击事件

面包屑项不接收 onClick 回调，点击任意可点击项后监听 item-click 获取 detail.item 即可。

点击面包屑项查看事件
{{$data.title}} 
// HTML
<solely-breadcrumb id="breadcrumb"></solely-breadcrumb>

// JavaScript
const breadcrumb = document.getElementById('breadcrumb');
const items = [
    { title: '首页' },
    { title: '组件' },
    { title: '面包屑' }
];
// 项内不支持 onClick 函数（attribute 会经 JSON 序列化丢函数），统一监听 item-click
breadcrumb.setAttribute('items', JSON.stringify(items));

// 监听点击事件（item-click 为自定义事件，不会与原生 click 混淆）
breadcrumb.addEventListener('item-click', (e) => {
    const item = e.detail.item;
    console.log('点击了:', item?.title);
});

CSS Part 自定义样式

通过 ::part() 伪元素可在 Shadow DOM 外部自定义面包屑内部样式，无需修改组件源码。

<!-- HTML -->
<solely-breadcrumb items="..."></solely-breadcrumb>

<!-- CSS：通过 ::part() 自定义样式 -->
<style>
  solely-breadcrumb::part(base) {
    background: #f0f5ff;
    border-radius: 8px;
    padding: 12px 16px;
    border: 1px solid #d6e4ff;
  }
  solely-breadcrumb::part(link) {
    color: #667eea;
    text-decoration: none;
  }
  solely-breadcrumb::part(link):hover {
    color: #1890ff;
    text-decoration: underline;
  }
  solely-breadcrumb::part(current) {
    color: #262626;
    font-weight: 600;
  }
  solely-breadcrumb::part(separator) {
    color: #667eea;
    font-weight: 700;
  }
</style>

使用链接

为面包屑项添加 href 属性，使其成为可点击的链接；最后一项带 href 时同样可点击，并保留 aria-current="page"。

const items = [
    { title: '首页', href: '/' },
    { title: '产品中心', href: '/products' },
    { title: '详情' }
];
breadcrumb.setAttribute('items', JSON.stringify(items));

API

属性

HTML 属性写法 JS 属性写法 说明 类型 默认值
items（JSON 字符串） items 面包屑项列表。HTML attribute 传 JSON 字符串（框架自动解析为数组），JS 属性直接赋 BreadcrumbItem[] BreadcrumbItem[] []
separator separator 分隔符 string '/'
label label 导航地标的可访问名称（映射到 <nav> 的 aria-label） string ''

事件

事件名 说明 回调参数
item-click 点击面包屑项时触发；所有可点击项都会派发，包括带 href 的导航项 CustomEvent<{ item: BreadcrumbItem }>
legacy-click 已废弃：旧版自定义 click 的改名兼容别名，仅在 0.x 期间保留 CustomEvent<{ item: BreadcrumbItem }>
click 原生 DOM 事件（由内部元素冒泡到宿主），组件不再额外合成同名的自定义事件 MouseEvent

从旧版 click 迁移

旧版组件在点击时会额外合成一次名为 click 的自定义事件，与原生 click 同名，导致同一个监听器在一次点击中执行两次。本次修复把该自定义事件改名为 legacy-click（detail 同为 { item }），原生 click 保持正常冒泡。迁移时请把依赖 detail.item 的 click 监听改为 item-click；过渡期可临时改听 legacy-click，后续大版本移除。 带 href 的项同样会派发 item-click，默认导航行为不受影响。 

// 迁移前：同名 click 会被原生事件与自定义事件各触发一次，且原生事件没有 detail
breadcrumb.addEventListener('click', (e) => {
    handle(e.detail.item);
});

// 迁移后：统一监听带 detail 的 item-click
breadcrumb.addEventListener('item-click', (e) => {
    handle(e.detail.item);
});

// 过渡期如需继续使用旧的自定义事件，可临时改听 legacy-click（后续大版本移除）
breadcrumb.addEventListener('legacy-click', (e) => {
    handle(e.detail.item);
});

实例属性（JS property）

属性名 说明 类型
items 获取/设置面包屑项 BreadcrumbItem[]
clickedItem 获取最后点击的面包屑项 BreadcrumbItem | null

CSS Part

Part 名称 说明 对应元素
base 面包屑根容器 <nav>
item 面包屑项包装器 <span>
link 可点击链接/文本 <a> / <span>
current 当前页文本 <span>
separator 分隔符 <span>

类型定义

// 面包屑项
interface BreadcrumbItem {
  title: string;           // 显示标题（必填）
  href?: string;          // 跳转链接（可选）；点击行为统一通过 item-click 事件处理
}

// 面包屑属性（JS property）
interface BreadcrumbProps {
  items: BreadcrumbItem[]; // HTML attribute 需传 JSON 字符串，由框架解析为数组
  separator: string;         // 分隔符，默认 '/'
}
