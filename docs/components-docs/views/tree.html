Tree 树形控件

树形控件，用于展示具有层级关系的数据。

基础用法

最简单的用法，通过 tree-data 属性传入树形数据。

<solely-tree 
  tree-data='[{"title":"父节点 1","key":"0-0","children":[...]},...]'
></solely-tree>

连接线

设置 show-line 属性显示节点之间的连接线。

<solely-tree show-line tree-data="..."></solely-tree>

默认展开全部

设置 default-expand-all 属性默认展开所有节点。

<solely-tree default-expand-all tree-data="..."></solely-tree>

多选

设置 multiple 属性支持多选节点。

<solely-tree multiple tree-data="..."></solely-tree>

可勾选

设置 checkable 属性显示勾选框。

<solely-tree checkable tree-data="..."></solely-tree>

禁用状态

设置 disabled 属性禁用整个树形控件，或在节点数据中设置 disabled 禁用特定节点。

<!-- 禁用整个树 -->
<solely-tree disabled tree-data="..."></solely-tree>

<!-- 禁用特定节点 -->
<solely-tree tree-data='[{"title":"父节点","key":"0-0","children":[{"title":"禁用节点","key":"0-0-1","disabled":true}]}]'></solely-tree>

Block 属性

设置 block 属性可使树形控件宽度撑满父容器。

<solely-tree block tree-data="..."></solely-tree>

内置搜索

设置 searchable 后自动渲染搜索框（可通过 part="search" / part="search-input" 自定义样式），输入即过滤；外部修改 search-value 或 .searchValue 也会自动重新过滤，无需手动调用 parseTreeData()。 搜索期间会临时展开命中路径，清空搜索值后自动恢复搜索前的展开状态。 

<solely-tree searchable tree-data="..."></solely-tree>

// 外部驱动搜索：赋值后自动过滤
tree.searchValue = 'vue'

CSS Part 自定义样式

通过 ::part() 伪元素可在 Shadow DOM 外部自定义树形控件内部样式，无需修改组件源码。 

<!-- HTML -->
<solely-tree checkable default-expand-all tree-data="..."></solely-tree>

<!-- CSS：通过 ::part() 自定义样式 -->
<style>
  solely-tree::part(base) {
    background: #fafafa;
    border-radius: 8px;
    padding: 12px;
  }
  solely-tree::part(node) {
    border-radius: 4px;
    transition: background 0.2s;
  }
  solely-tree::part(node):hover {
    background: #e6f7ff;
  }
  solely-tree::part(node-selected) {
    background: #1890ff;
    color: #fff;
  }
  solely-tree::part(switcher) {
    color: #1890ff;
  }
</style>

事件处理

监听 select、expand、check 事件处理树形控件的交互。

事件日志（最近5条）：
等待交互...
<!-- HTML -->
<solely-tree 
  multiple
  checkable
  @select="handleSelect(event)"
  @expand="handleExpand(event)"
  @check="handleCheck(event)"
  tree-data="..."
></solely-tree>

<!-- JavaScript -->
const treeEl = document.querySelector('solely-tree');

// select 事件 - 选中节点时触发
treeEl.addEventListener('select', (e) => {
  const { node, selectedKeys } = e.detail;
  console.log('选中节点:', node, '选中 keys:', selectedKeys);
});

// expand 事件 - 展开/收起节点时触发
treeEl.addEventListener('expand', (e) => {
  const { node, expandedKeys } = e.detail;
  console.log('展开节点:', node, '展开 keys:', expandedKeys);
});

// check 事件 - 勾选节点时触发
treeEl.addEventListener('check', (e) => {
  const { node, checkedKeys } = e.detail;
  console.log('勾选节点:', node, '勾选 keys:', checkedKeys);
});

异步加载与父子不联动（0.8.0）

点击「异步父节点」左侧的 ▶ 展开箭头即可加载：箭头位置会变成旋转的加载圆环，约 600ms 后出现两个异步子节点；加载期间忽略重复点击，同级箭头不会被带着动一下。勾选 「模拟加载失败」 后展开会抛错、圆环消失且箭头恢复可点，取消勾选再点 ▶ 即完成失败重试验收（对应验收清单 #19）。loadData 是 property 回调。check-strictly 下勾选父节点不会联动子节点。初始全部未勾选，勾选父节点后子节点不应变化；整棵树只应有 1 个 Tab 停点。

loadData 异步加载（展开「异步父节点」）
checkStrictly（父子勾选不联动）
tree.loadData = async node => {
  await new Promise(r => setTimeout(r, 600));
  return [{ key: node.key + '-a', title: '异步子节点 A' }];
};
<solely-tree checkable check-strictly ...></solely-tree>

键盘支持

按键 说明
ArrowDown / ArrowUp 移动到下一个 / 上一个可见节点（循环）
ArrowRight 展开节点；已展开时聚焦第一个子节点
ArrowLeft 折叠节点；已折叠时聚焦父节点
Home / End 第一个 / 最后一个可见节点
Enter 选中节点
Space 可勾选时勾选，否则选中节点

焦点采用 roving tabindex，仅第一个可导航节点 tabindex="0"，其余为 -1。

事件

事件名 说明 回调参数
select 选中节点时触发（自定义事件） CustomEvent<TreeSelectEventDetail>
expand 展开/收起节点时触发（自定义事件）；expandAll() / collapseAll() 批量操作时 detail.node 缺省，仅含 expandedKeys CustomEvent<TreeExpandEventDetail>（node 可选）
check 勾选节点时触发（自定义事件） CustomEvent<TreeCheckEventDetail>
change 选中 / 展开 / 勾选等状态变化时触发（原生事件，无 detail）；expandAll() / collapseAll() 以及写入 selectedKeys / value / checkedKeys / expandedKeys 也会派发。搜索过滤只更新视图，不派发 change。通过 event.target.getSelectedKeys() / getCheckedKeys() / getExpandedKeys() 读取最新状态 Event

方法

方法名 说明 参数 返回值
setTreeData(data) 设置树形数据 data: TreeNode[] void
value 获取/设置选中的节点 keys（同 selectedKeys，支持属性读写） string[] []
selectedKeys 获取/设置选中的节点 keys（支持属性读写） string[] []
checkedKeys 写入勾选的节点 keys（仅提供 setter，会写回树数据并派发 change；不支持 HTML attribute）。读取请使用 getCheckedKeys() string[] -
expandedKeys 写入展开的节点 keys（仅提供 setter，会写回树数据并派发 change；不支持 HTML attribute）。读取请使用 getExpandedKeys() string[] -
getSelectedKeys() 获取选中的 keys - string[]
getCheckedKeys() 获取勾选的 keys - string[]
getExpandedKeys() 获取展开的 keys - string[]
expandAll() 展开所有节点。对未加载的懒节点会并发调用 loadData，但新返回的节点不会自动继续递归加载（避免服务端未标记叶子时无限请求）； 加载完成后再次派发 expand（含 expandedKeys）与 change。 - void

类型定义

// 树形节点
interface TreeNode {
  title: string;        // 节点标题
  key: string;          // 节点唯一标识
  children?: TreeNode[]; // 子节点
  disabled?: boolean;    // 是否禁用
  selectable?: boolean; // 是否可选中
  checkable?: boolean;  // 是否可勾选
  isLeaf?: boolean;     // 是否为叶子节点
  icon?: string;       // 自定义图标
}

// 组件属性接口
interface TreeProps {
  treeData?: string | TreeNode[]; // 树形数据（JSON字符串或节点数组）
  showLine?: boolean;   // 是否显示连接线
  multiple?: boolean;   // 是否支持多选
  checkable?: boolean;  // 是否显示勾选框
  defaultExpandAll?: boolean; // 是否默认展开所有节点
  disabled?: boolean;   // 是否禁用
  searchable?: boolean; // 是否可搜索
  searchValue?: string; // 搜索值
  block?: boolean;      // 是否撑满父容器宽度
}

// select 事件 detail
interface TreeSelectEventDetail {
  selectedKeys: string[];
  selectedNodes: TreeNode[];
  node: TreeNode;
}

// check 事件 detail
interface TreeCheckEventDetail {
  checkedKeys: string[];
  checkedNodes: TreeNode[];
  node: TreeNode;
}

// expand 事件 detail；expandAll()/collapseAll() 时 node 缺省
interface TreeExpandEventDetail {
  expandedKeys: string[];
  node?: TreeNode;
}
