快速上手

了解如何在项目中使用 Solely UI。

安装

UI 组件库随着 Solely 框架一起分发，只需安装 Solely 即可获得全套组件。

# npm
npm install solely

# yarn
yarn add solely

# pnpm
pnpm add solely

浏览器支持基线

组件库依赖原生 Web Components 能力：表单关联（formAssociated / ElementInternals）、 WeakRef 与 requestSubmit。支持基线为 Chrome / Edge 84+、Firefox 98+、Safari 16.4+；Safari 16.4 是首个支持表单关联自定义元素的版本， 也是本库的硬底线。

低于基线时：模块仍可导入，但运行行为会失败——缺少 WeakRef 时响应式系统初始化直接抛 TypeError；缺少 requestSubmit 时 nativeType="submit" 的按钮点击后表单不会提交； 缺少 formAssociated / ElementInternals 时表单关联会告警并降级为不参与表单。 本库不提供 polyfill，也不做静默降级。

评估结论：不为 WeakRef / requestSubmit 增加存在性守卫。两者在声明基线内均已受支持， 守卫只会覆盖基线以下的浏览器；而那类环境同时缺少 ElementInternals，无法获得可用的组件语义。 增加守卫会把「环境不达标」伪装成「组件静默失效」，反而增加排查成本。低于基线请升级浏览器。

服务端渲染（SSR）限制

服务端可以安全导入，但不能实例化。导入组件模块不会注册元素（装饰器检测到没有 window / customElements 时会跳过注册），主题自动注入也会检测 document 后跳过， 因此 Node 环境下 import 'solely/components/elements/button' 不会抛错。

构造实例会立即失败：基类构造函数会调用 this.attachShadow()，Node 中没有 DOM，报 attachShadow is not a function；直接调用组件实例方法或主题 API 也可能访问 document。 

// ✅ 服务端：只导入模块，输出 HTML 标签字符串
import 'solely/components/elements/button';
const html = '<solely-button type="primary">提交</solely-button>';

// ❌ 服务端：不要实例化，也不要调用依赖 DOM 的 API
// new SolelyButton();  // attachShadow is not a function

推荐用法：服务端只做「导入 + 输出标签字符串」，把组件模块放到客户端入口（hydration 之前）导入； Next.js / Nuxt 等框架中请在客户端侧注册组件，不要放进只在服务端执行的模块。当前版本不提供 SSR 适配层 （无声明式 shadow DOM 与 hydration 支持）。

引入组件

你可以按需引入单个组件，也可以引入所有组件。

// 按需引入单个组件（推荐）
import 'solely/components/elements/button';
import 'solely/components/elements/input';
import 'solely/components/elements/card';

// 或者引入所有组件
import 'solely/components';

引入样式

引入 solely/components 时会自动注入主题 CSS 变量，无需额外操作；仅按需引入单个组件、或站点启用严格 CSP（禁止内联样式）时，才需要手动引入主题文件。

// 引入全部组件：主题 CSS 变量自动注入
import 'solely/components';

// 仅按需引入单个组件时，手动引入主题 CSS（必需）
import 'solely/components/theme/variables.css';
import 'solely/components/elements/button';

使用组件

在 HTML 中直接使用组件标签。

<!-- 基础按钮 -->
<solely-button type="primary">Primary Button</solely-button>

<!-- 输入框 -->
<solely-input placeholder="请输入内容"></solely-input>

<!-- 带图标的按钮 -->
<solely-button type="primary" icon="search">
    搜索
</solely-button>

属性写法：HTML 与 JavaScript

HTML 中直接写在标签上的属性必须使用 kebab-case（短横线小写）写法，组件文档属性表的「HTML 属性写法」列即为此列； 通过 JavaScript 读写组件实例时使用同名的 camelCase 属性（property），对应「JS 属性写法」列。 单词型属性（如 size、disabled）两种写法一致。 

<!-- HTML：kebab-case -->
<solely-pagination show-total total="100"></solely-pagination>

// JavaScript：camelCase property
const pagination = document.querySelector('solely-pagination');
pagination.showTotal = true;

// 动态绑定同样使用 JS 属性写法（绑定表达式直接写入 property）
<solely-tabs :activeKey="this.$data.currentKey"></solely-tabs>

布尔属性：写值即可关闭

布尔属性同时支持「出现即开启」和「按值解析」：disabled、disabled=""、disabled="true" 为开启； disabled="false" / disabled="0"（大小写不敏感、首尾空白忽略）为关闭；移除属性回退到组件默认值。 默认开启的属性（如 progress 的 show-info、table 的 local-sort / local-filter）用 ="false" 真正关闭。 注意 ="false" 从 0.8.0 起不再按「存在即 true」处理，旧代码中写 disabled="false" 期望禁用的写法需要改为 disabled / disabled="true"。

命令式组件

Solely UI 提供了一系列命令式组件，可以通过 JavaScript 直接调用。

import { Message, Modal, Drawer } from 'solely/components/commands';

// Message 全局提示
Message.success('操作成功！');
Message.error('操作失败！');
Message.warning('警告信息');
Message.info('提示信息');

// Modal 对话框
Modal.confirm({
    title: '确认删除',
    content: '确定要删除此项吗？',
    onOk: () => {
        console.log('用户确认');
    }
});

// Drawer 抽屉
const drawer = Drawer.open({
    title: '抽屉标题',
    content: '抽屉内容',
    placement: 'right'
});

// 关闭抽屉
drawer.close();

生命周期与资源释放

组件从 DOM 移除（remove()、父节点被删除或框架卸载）时，disconnectedCallback 只停止当前渲染调度， 不会销毁渲染树、响应式 observer 与内部监听器；临时移出后再插回，组件仍可继续使用。

确认组件不再使用时，请调用公开的 dispose() 彻底释放。命令式浮层（Modal / Drawer / Tooltip / Popconfirm） 会在关闭动画结束后自动 dispose()；其他场景请在永久移除前显式调用。 

// 临时移出：稍后插回可复用，无需 dispose
container.removeChild(myButton);
container.appendChild(myButton);

// 永久移除：调用 dispose() 释放渲染树、observer 与内部监听器
myButton.dispose();
myButton.remove();

TypeScript 支持

Solely UI 提供完整的 TypeScript 类型定义。

import { Message, Modal } from 'solely/components/commands';
import type { MessageOptions, ModalOptions } from 'solely/components/commands';

// 使用类型定义
const messageOptions: MessageOptions = {
    content: '提示信息',
    duration: 3000
};

const modalOptions: ModalOptions = {
    title: '标题',
    content: '内容',
    onOk: () => {
        console.log('确定');
    }
};

Message.open(messageOptions);
Modal.open(modalOptions);

主题定制

通过 CSS 变量自定义主题。直接写 CSS 变量时，派生色（hover / active / light）需要自己一并提供。

/* 自定义主题变量 */
:root {
  --solely-primary: #1890ff;
  /* 派生色需同步提供，否则组件仍使用默认主题的派生色 */
  --solely-primary-hover: #46a6ff;
  --solely-primary-active: #147ad9;
  --solely-primary-light: #e8f4ff;
  --solely-success: #52c41a;
  --solely-warning: #faad14;
  --solely-error: #f5222d;
  --solely-font-size-md: 14px;
  --solely-border-radius-md: 6px;
}

/* 暗黑模式 */
[data-theme="dark"] {
  --solely-bg-color: #141414;
  --solely-component-bg: #1f1f1f;
}

主题样式

主题在首次导入时初始化：优先使用本地保存的选择，其次以系统偏好作为初始默认值，再没有则使用浅色；初始化后以保存的选择为准，不会持续跟随系统主题变化。引入全部组件时主题 CSS 变量会自动加载；按需引入时需要单独导入主题样式。

// 引入全部组件（主题 CSS 已包含）
import 'solely/components';

// 按需引入时需要先导入主题 CSS
import 'solely/components/theme/variables.css';
import 'solely/components/elements/button';

// 主题只在首次导入时初始化，之后需要时通过 API 手动切换
import { setTheme, toggleTheme } from 'solely/components/theme';
toggleTheme(); // 切换明暗主题

// setTheme 接收一个配置对象；主色放在 colors 中，会自动派生 hover / active / light 三个变量
setTheme({ theme: 'light', colors: { primary: '#1890ff' } });
// 等价于写入：--solely-primary-hover: #46a6ff
//           --solely-primary-active: #147ad9
//           --solely-primary-light: #e8f4ff

// 显式传入同名派生变量时以显式值为准；var(--x) 或颜色名无法解析，不派生
setTheme({ theme: 'light', colors: { primary: '#1890ff', 'primary-hover': '#40a9ff' } });
