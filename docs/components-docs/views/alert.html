Alert 警告提示

用于页面中展示重要的提示信息，适用于需要引起用户注意的场景。

基础用法

最简单的用法，适用于简短的提示。

<solely-alert type="info" message="Info text"></solely-alert>
<solely-alert type="success" message="Success text"></solely-alert>
<solely-alert type="warning" message="Warning text"></solely-alert>
<solely-alert type="error" message="Error text"></solely-alert>

可关闭

显示关闭按钮，点击可关闭警告提示。

<solely-alert type="info" message="Info Text" closable></solely-alert>
<solely-alert type="success" message="Success Text" closable></solely-alert>
<solely-alert type="warning" message="Warning Text" closable></solely-alert>
<solely-alert type="error" message="Error Text" closable></solely-alert>

含有辅助性文字介绍

含有辅助性文字介绍的警告提示。

<solely-alert type="info" message="Info Text"
  description="Detailed description..." show-icon></solely-alert>
<solely-alert type="success" message="Success Text"
  description="Detailed description..." show-icon></solely-alert>
<solely-alert type="warning" message="Warning Text"
  description="Detailed description..." show-icon></solely-alert>
<solely-alert type="error" message="Error Text"
  description="Detailed description..." show-icon></solely-alert>

事件监听

监听关闭事件，点击关闭按钮查看事件日志。

事件日志（最近5条）：
等待交互...
<solely-alert type="info" message="Click the close button" closable @close="handleClose()"></solely-alert>

<script>
function handleClose() {
    console.log('Alert closed');
}
</script>

块级显示

添加 block 属性可以让警告提示宽度占满父容器。

<!-- 块级显示，宽度占满父容器 -->
<solely-alert block type="info" message="块级显示的 Info 警告提示"></solely-alert>
<solely-alert block type="success" message="块级显示的 Success 警告提示"></solely-alert>

使用插槽自定义

通过插槽自定义图标、关闭按钮或内容区域。

🚀 ❌ ✅ 👋
自定义标题
这是通过默认插槽传入的自定义内容
 
<!-- 自定义图标 -->
<solely-alert type="info" message="自定义图标" show-icon>
    <span slot="icon">🚀</span>
</solely-alert>

<!-- 自定义关闭按钮 -->
<solely-alert type="warning" message="自定义关闭按钮" closable>
    <span slot="close-icon">❌</span>
</solely-alert>

<!-- 完全自定义内容（不使用 message/description） -->
<solely-alert type="success" show-icon closable>
    <span slot="icon">✅</span>
    <span slot="close-icon">👋</span>
    <div style="font-weight: bold;">自定义标题</div>
    <div style="font-size: 12px;">自定义内容</div>
</solely-alert>

CSS Part 自定义样式

通过 ::part() 伪元素可在 Shadow DOM 外部自定义警告提示内部样式。

<!-- HTML -->
<solely-alert type="info" message="自定义样式警告" closable show-icon></solely-alert>

<!-- CSS：通过 ::part() 自定义样式 -->
<style>
  solely-alert::part(base) {
    border-radius: 8px;
    border: 2px solid #667eea;
    background: #f8f9ff;
  }
  solely-alert::part(message) {
    font-weight: 600;
    color: #333;
  }
  solely-alert::part(close) {
    color: #667eea;
    font-size: 18px;
  }
</style>

API

属性

HTML 属性写法 JS 属性写法 说明 类型 默认值
type type 指定警告提示的样式，有四种选择：info、success、warning、error string info
message message 警告提示内容 string -
description description 警告提示的辅助性文字介绍 string -
closable closable 是否显示关闭按钮 boolean false
show-icon showIcon 是否显示辅助图标；默认 false（不带图标），需要图标时写 show-icon 或 show-icon="true"，show-icon="false" 保持关闭 boolean false
icon icon 自定义图标文本，需配合 show-icon 才显示；未设置（null）时按 type 使用内置线性 SVG 图标（info / success / warning / error）；icon="" 表示不渲染图标（存在 icon 插槽时仍显示插槽内容） string -
block block 是否块级显示 boolean false
auto-close autoClose 自动关闭时长（毫秒），值为 0 时不自动关闭；关闭时派发 close 事件，detail.source 为 'auto' number 0

事件

事件名 说明 回调参数
close 关闭时触发（自定义事件，可取消）；点击关闭按钮时 detail.source 为 'user'，auto-close 自动关闭时为 'auto' CustomEvent<{ source: 'user' | 'auto' }>

插槽

插槽名 说明 默认值
icon 自定义图标，需要设置 show-icon 属性才显示，优先级高于根据 type 自动选择的图标 根据 type 自动选择内置线性 SVG 图标（info / success / warning / error）
close-icon 自定义关闭按钮图标，需要设置 closable 属性才显示，优先级高于默认关闭图标 线性 × 图标
默认插槽 自定义内容区域，会显示在 message 和 description 之后 -

方法

方法名 说明 参数 返回值
setMessage 设置消息内容 message: string void

类型定义

type AlertType = 'info' | 'success' | 'warning' | 'error';

interface AlertProps {
    type?: AlertType;
    message?: string;
    description?: string;
    closable?: boolean;
    showIcon?: boolean;
    icon?: string;
    block?: boolean;
    autoClose?: number; // 自动关闭时长（毫秒），0 表示不自动关闭
}
