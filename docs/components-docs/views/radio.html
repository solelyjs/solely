Radio 单选框

单选框组件，用于在多个选项中进行单选。

基础用法

最简单的用法，通过 checked 属性控制选中状态，使用相同的 name 属性来分组。

Apple Banana Orange 
<solely-radio name="fruit" value="apple" checked>Apple</solely-radio>
<solely-radio name="fruit" value="banana">Banana</solely-radio>
<solely-radio name="fruit" value="orange">Orange</solely-radio>

分组边界

name 相同的单选框只在同一分组容器内互斥。分组容器按以下顺序确定：最近的 role="radiogroup" 或 data-radio-group 容器、最近的 <form>；都没有时以所在根节点（document / shadow root）为界。 因此两个独立表单或独立分组容器内的同名单选框不会互相取消。

表单 A：选项 1 表单 A：选项 2
表单 B：选项 1 表单 B：选项 2
分组 C：选项 1 分组 C：选项 2 
<form>
  <solely-radio name="group-a" value="a1" checked>选项 1</solely-radio>
  <solely-radio name="group-a" value="a2">选项 2</solely-radio>
</form>
<form>
  <!-- 同样 name="group-a"，但与上一个 form 互不影响 -->
  <solely-radio name="group-a" value="b1" checked>选项 1</solely-radio>
  <solely-radio name="group-a" value="b2">选项 2</solely-radio>
</form>

禁用状态

通过 disabled 属性禁用单选框，禁用后无法交互。

Disabled Disabled Checked 
<solely-radio disabled>Disabled</solely-radio>
<solely-radio disabled checked>Disabled Checked</solely-radio>

颜色类型

通过 type 属性设置不同的颜色主题，可选 primary、success、warning、error。

Primary Success Warning Error 
<solely-radio type="primary" checked>Primary</solely-radio>
<solely-radio type="success" checked>Success</solely-radio>
<solely-radio type="warning" checked>Warning</solely-radio>
<solely-radio type="error" checked>Error</solely-radio>

块级模式

通过 block 属性使单选框占满父容器宽度，适用于表单布局场景。

选项一（block 模式） 选项二（block 模式） 选项三（block 模式） 
<solely-radio name="block-demo" value="option1" block>选项一（block 模式）</solely-radio>
<solely-radio name="block-demo" value="option2" block>选项二（block 模式）</solely-radio>
<solely-radio name="block-demo" value="option3" block>选项三（block 模式）</solely-radio>

事件处理

监听 change 事件获取选中的值。点击单选框查看效果。

Pizza Burger Sushi 选中: {{$data.selectedValue}} 
<!-- HTML -->
<solely-radio name="food" value="pizza" @change="handleChange">Pizza</solely-radio>
<solely-radio name="food" value="burger" @change="handleChange">Burger</solely-radio>
<span>选中: {{$data.selectedValue}}</span>

<!-- JavaScript -->
const radioEls = document.querySelectorAll('solely-radio[name="food"]');

radioEls.forEach(radio => {
  radio.addEventListener('change', (e) => {
    const target = e.target;
    const value = target.value;
    const checked = target.checked;
    if (checked) {
      console.log(`选中: ${value}`);
    }
  });
});

双向绑定

使用 s-model 指令实现双向数据绑定，绑定的是 checked 属性。适用于需要程序化控制选中状态的场景。

选项 A 当前状态: {{$data.modelRadio1 ? '已选中' : '未选中'}}
选中 取消 切换 
<!-- 使用 s-model 实现双向绑定（绑定 checked 属性） -->
<solely-radio s-model="isSelected">
  选项 A
</solely-radio>

<!-- JavaScript -->
// s-model 会自动绑定 checked 属性和监听 change 事件
// solely-radio 的 model 配置: { prop: 'checked', event: 'change' }

// 可以通过代码控制选中状态
this.isSelected = true;   // 选中
this.isSelected = false;  // 取消选中

使用插槽自定义内容

通过默认插槽自定义单选框的文本内容，可以包含 HTML 元素实现更丰富的展示。

蓝色选项 ⭐ 带图标的选项 标签样式 
<!-- 带样式的文本 -->
<solely-radio name="slot-demo1" value="option1">
  <span style="color: #1890ff; font-weight: bold;">蓝色选项</span>
</solely-radio>

<!-- 带图标的选项 -->
<solely-radio name="slot-demo2" value="option2">
  <span style="color: #faad14; margin-right: 4px;">⭐</span>
  带图标的选项
</solely-radio>

<!-- 标签样式 -->
<solely-radio name="slot-demo3" value="option3">
  <span style="background: var(--solely-success-light); color: var(--solely-success); padding: 2px 8px; border-radius: 4px; border: 1px solid var(--solely-success);">标签样式</span>
</solely-radio>

CSS Part 自定义样式

通过 ::part() 伪元素可在 Shadow DOM 外部自定义单选框内部样式。

自定义样式单选框 
<!-- HTML -->
<solely-radio name="part-demo" checked>自定义样式单选框</solely-radio>

<!-- CSS：通过 ::part() 自定义样式 -->
<style>
  solely-radio::part(input) {
    border: 2px solid #667eea;
    background: #f8f9ff;
  }
  solely-radio::part(content) {
    font-weight: 600;
  }
</style>

API

属性

HTML 属性写法 JS 属性写法 说明 类型 默认值
checked checked 指定当前是否选中（支持属性读写） boolean false
default-checked defaultChecked 表单重置时回到的默认选中状态 boolean false
disabled disabled 是否禁用 boolean false
content content 单选框文本内容 string ''
value value 单选框的值，用于标识选项（支持属性读写） string ''
name name 单选框名称，用于分组，同组的单选框互斥。分组范围为最近的 <form>、 role="radiogroup" 或 data-radio-group 容器；都没有时以所在根节点（document / shadow root）为界。 string ''
group group 显式分组名，同 group 值的单选框互斥，无需依赖 name string ''
type type 颜色类型，可选 primary、success、warning、error string 'primary'
block block 是否块级元素，占满父容器宽度 boolean false

表单关联

设置 name（或 group）后，solely-radio 作为表单关联自定义元素参与提交： 仅选中项提交一个条目（value 未设置或为空时按 'on' 提交），未选中不产生条目。 formResetCallback 回到 default-checked，所属 fieldset 禁用时会同步清空提交值并锁定交互。 

<!-- 同一 name 分组互斥，选中项以 name=color、value=red 提交 -->
<form>
  <solely-radio name="color" value="red" default-checked>红</solely-radio>
  <solely-radio name="color" value="blue">蓝</solely-radio>
  <button type="submit">提交</button>
</form>

公开的有效性接口与原生控件一致：validity、validationMessage、willValidate、 checkValidity()、reportValidity()、setCustomValidity(message)。

键盘支持

按键 说明
Enter 选中当前单选框
Space 选中当前单选框
ArrowRight / ArrowDown 在分组内移动到下一个单选框并将其选中；仅在显式分组（role="radiogroup" 或 data-radio-group）内，或同一 name / group 且位于同一分组边界（最近的 radiogroup 容器 → form → 根节点）内生效，独立单选框不响应
ArrowLeft / ArrowUp 与 ArrowRight / ArrowDown 相反方向移动；分组条件相同
Tab 分组内采用 roving tabindex：仅选中项（无选中项时为第一个可用项）为 tabindex="0"，其余为 -1

类型定义

// 单选框颜色类型
type RadioType = 'primary' | 'success' | 'warning' | 'error';

// 单选框属性接口
interface RadioProps {
  checked?: boolean;   // 是否选中
  disabled?: boolean;  // 是否禁用
  content?: string;   // 文本内容
  value?: string;     // 单选框值
  name?: string;      // 分组名称
  type?: RadioType;   // 颜色类型
  block?: boolean;   // 是否块级元素
}
